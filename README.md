# iPhone 17 Pro Max exoskeleton case

Parametric two-colour "exoskeleton" case, generated by `generate_case.py`
(`pip install numpy trimesh manifold3d && python3 generate_case.py`).

Overall size 82.6 × 168.0 mm, cavity 79 × 164 mm, back plate 3 mm (taken from the reference STL).

| File (`stl/`) | Colour | Qty |
|---|---|---|
| `shell_blue.stl` | blue | 1 – back shell, full-height top/bottom walls, low side lips, raised camera bezel, MagSafe ring groove |
| `corner_{top,bottom}_{left,right}_orange.stl` | orange | 4 – wrap-around corner caps with front lip; tongue joints into the shell |
| `iphone17_promax_exoskeleton_assembled.stl` | – | preview of everything together |

Print in TPU (or flexible PETG), shell back-down, corners back-down. Tweak the constants at the top of
`generate_case.py` (clearance, camera opening, lip heights) and re-run. The camera opening size/position and
"SUMIT" back text (debossed 0.4 mm, set `LOGO_TEXT`) are approximations of the photos – verify the camera cut-out against your phone before printing.
